#    Работа с вакансиями HH.ru

Простая консольная программа для поиска и управления вакансиями с hh.ru.

##  Быстрый старт

```bash
# Установка
pip install -e .

# Запуск
python main.py

# Тесты
python tests/simple_test.py
```


# Структура проекта

```
coursework2.1/
├── data/                 # Папка для хранения JSON-файлов с вакансиями
├── src/                  # Исходный код программы
│   ├── __init__.py      # Файл для создания Python-пакета
│   ├── api.py           # Модуль для работы с API HH.ru
│   ├── vacancy.py       # Модель данных вакансии
│   └── storage.py       # Модуль для работы с файлами JSON
├── tests/               # Папка с тестами
│   └── simple_test.py   # Простые тесты для проверки функционала
├── main.py              # Главный исполняемый файл
├── pyproject.toml       # Файл с зависимостями проекта
└── README.md            # Документация проекта
```

## 🚀 Основные функции
| Функция | Описание |
|--------|----------|
| 🔍 **Поиск вакансий** | Ищет вакансии на HH.ru по ключевым словам |
| 📋 **Просмотр всех вакансий** | Показывает все сохранённые вакансии |
| 💰 **Топ-N по зарплате** | Вывод вакансий с самой высокой зарплатой |
| 🔎 **Поиск по описанию** | Фильтрует вакансии по ключевым словам в описании |
| 🗑️ **Удаление вакансий** | Удаляет вакансию по URL-ссылке |

---

## 💾 Хранение данных
- Файл: `data/vacancies.json`
- Формат: JSON
- Папка `data/` создаётся автоматически при первом запуске.
